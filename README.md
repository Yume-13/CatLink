# CatLink

CatLink shares an Android phone's internet connection with a Windows PC over USB or Wi-Fi using adb. A Windows tray app creates a virtual network adapter and passes each connection through adb to the CatLink Android app, which opens every socket itself, so the traffic leaves the phone as that app's own data.

This is intended for personal use and uploaded here for convenience. We do not mind if others find it useful, but use at your own risk.
